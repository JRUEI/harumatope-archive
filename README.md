## 🌟 核心功能特色

- 🎬 **劇院級 YouTube 雙向同步連動**：
  - 整合官方 YouTube 播放器與精準秒數索引。
  - **點擊跳轉**：點選任一句逐字稿或時間戳，影片立即精準跳轉並自動播放。
  - **同步高亮**：隨影片播放進度，即時鎖定並同步推進當前對話。
- 💬 **無框對話流即時字幕群（劇本台詞風）**：
  - 影片正下方常駐即時字幕群，消除冗餘外框，以純淨劇本對話流呈現。
  - 支援使用者自訂 **1 ~ 5 句** 同步預讀句數，偏好自動跨集數保存。
- 🎯 **智慧畫面定位**：
  - 一鍵自動平滑捲動視窗，底部精準對齊字幕群留白中點，頂部露出 YouTube 播放時間軸與控制列，帶來最佳觀看視野。
- 📑 **側邊全文檢索抽屜**：
  - 隨時由右側邊緣或控制列喚出全篇逐字稿抽屜。
  - 支援關鍵字即時搜尋與高亮標記、自動跟隨滾動開關、一鍵回跳播放處。
- 📝 **三層次結構化閱讀**：
  - **【精簡總結】**：3 ~ 6 條核心重點，1 分鐘掌握全集精華。
  - **【無損還原】**：以話題標籤與話題卡片形式，完整重現閒聊、來信與單元脈絡。
  - **【完整逐字稿】**：一對一完整繁體中文翻譯，保留語境、笑點與專業術語。

## 🛠️ 技術架構

- **框架**：[Next.js 16](https://nextjs.org/)（Turbopack, App Router, SSG 靜態全量預渲染）
- **核心庫**：React 19, TypeScript 5
- **樣式**：Tailwind CSS 4, next-themes (支援暗黑／亮色主題切換)
- **內容解析**：gray-matter, react-markdown
- **圖示庫**：Lucide React
- **影音連動**：YouTube IFrame Player API (雙向進度輪詢器)
